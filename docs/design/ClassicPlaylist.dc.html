The sidebar takes width from the video rather than covering it. Row 7 shows the unreachable-file state — greyed, still listed, never silently dropped from the queue.
SplitterDrag to resize, double-click to collapse. Width persists per window, not per file. Minimum 240 px before it snaps shut.
Row anatomyIndex, title, container/codec/resolution, duration. The codec line is what makes a playlist useful for anyone auditing a library.
Three row statesPlaying (accent fill, 3 px marker), hovered (warm grey), missing (greyed with the reason inline). Selection is separate from playing.
OrderingDrag to reorder; the queue is the source of truth for next/previous. Shuffle picks without repetition until the queue is exhausted.
Import safetyAdding a folder scans one level for known extensions and probes nothing until a row is actually played — opening a playlist must never touch every file.
