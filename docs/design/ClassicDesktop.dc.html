Nothing overlays the picture. Every control has a permanent home, so muscle memory works and the window never hides something you were reading.
Menu barFull command surface, every entry showing its accelerator. This is the direction's whole argument: discoverability without a search box.
Letterbox fillBars are the surface's own background, painted by the shader clear colour — not drawn widgets. Keeps aspect handling in one place.
Elapsed / remainingBoth ends labelled. Click either to toggle between remaining and total — the one thing everyone reaches for and nobody can find.
Tactile buttons32 px, 1 px border, one-stop gradient, pressed state inverts it. Play/pause is 40 px and darker-bordered so the hand finds it without looking.
Status barLive from pad caps and stream tags, not from the filename. The accelerator flag turns amber the moment playback falls back to software decode.
KeyboardEvery control is tab-reachable with a visible focus ring; menu accelerators work with the menu closed. No pointer-only actions anywhere.
