Stream copy — no re-encode, no quality loss. Cut lands on the nearest keyframe before In (−0.83 s) unless re-encode is chosen.
Two different jobs on one screen: the chip records a live stream as it arrives; the in/out selection cuts a range out of what is already on disk.
Live capture chipOnly appears while a network source is being written to disk. Shows elapsed, bytes and the destination path — nothing records without saying where.
Selection regionBoth handles drag; the playhead moves independently inside the region so you can review the cut without disturbing it. Shift-drag moves the whole region.
Keyframe honestyA stream copy cannot cut mid-GOP, so the panel states the real offset rather than silently shifting the in point. Re-encode is offered for a frame-exact cut.
PipelineA tee after the demuxer feeds queue → matroskamux → filesink. The decode and display branch is untouched, so playback never stutters while exporting.
Trust boundaryExport runs in the same sandboxed child as decode, writing through a single pre-opened file descriptor — the media process never gains a path of its own choosing.
